# 🎨 Цветовая схема - Военная тематика

## Обзор
Приложение использует военную темно-зеленую цветовую схему, вдохновленную дизайном министерства обороны.

## 🎯 Быстрая смена цветов

### Основной файл темы
Все цвета определены в файле: `styles/theme.ts`

### Основные цвета (легко изменяемые)

```typescript
primary: {
  from: '#1a4d2e',    // темно-зеленый (начало градиента)
  to: '#0d2818',      // очень темно-зеленый (конец градиента)
  solid: '#1a4d2e',   // основной зеленый
  light: '#2d6a4f',   // светлый зеленый
  dark: '#0d2818',    // темный зеленый
}

accent: {
  green: '#4ade80',   // яркий акцент (заголовки, иконки)
  olive: '#84a98c',   // оливковый (подзаголовки)
  gold: '#d4af37',    // золотой (предупреждения)
}
```

## 📍 Где применяются цвета

### Header (Шапка)
- **Файл:** `app/components/Manual/Header.tsx`
- **Градиент:** `from-[#0d2818] via-[#1a4d2e] to-[#0d2818]`
- **Граница:** `border-[#2d6a4f]/50`

### Sidebar (Боковая панель)
- **Файл:** `app/components/Manual/Sidebar.tsx`
- **Фон:** `from-[#1a4d2e]/30 to-[#0d2818]/30`
- **Активный элемент:** `bg-[#1a4d2e]/80`
- **Ховер:** `hover:bg-[#2d6a4f]/30`

### Main Content (Основной контент)
- **Файл:** `app/page.tsx`
- **Фон:** `from-[#1a4d2e]/20 to-[#0d2818]/20`
- **Заголовки:** `text-[#4ade80]` с границей `border-[#4ade80]/50`

### Background (Фон страницы)
- **Файл:** `app/styles/globals.css`
- **Анимированный градиент:** 
```css
background: linear-gradient(135deg, 
  #0a1612 0%,    /* очень темный */
  #1a4d2e 25%,   /* темно-зеленый */
  #0d2818 50%,   /* темный */
  #1a4d2e 75%,   /* темно-зеленый */
  #0a1612 100%   /* очень темный */
);
```

## 🔄 Как изменить тему полностью

### Вариант 1: Синяя тема (пример)
В `styles/theme.ts` замените:
```typescript
primary: {
  from: '#1e3a8a',    // темно-синий
  to: '#0c1e4a',      // очень темно-синий
  solid: '#1e3a8a',
  light: '#3b82f6',
  dark: '#0c1e4a',
}

accent: {
  green: '#60a5fa',   // светло-синий
  olive: '#93c5fd',   // голубой
  gold: '#fbbf24',    // желтый
}
```

### Вариант 2: Красная тема (пример)
```typescript
primary: {
  from: '#7f1d1d',    // темно-красный
  to: '#450a0a',      // очень темно-красный
  solid: '#7f1d1d',
  light: '#dc2626',
  dark: '#450a0a',
}

accent: {
  green: '#f87171',   // светло-красный
  olive: '#fca5a5',   // розовый
  gold: '#fbbf24',    // золотой
}
```

## 📝 Автоматическая замена цветов

После изменения цветов в `styles/theme.ts`, выполните глобальную замену в файлах:

### 1. Header.tsx
Найти: `#1a4d2e`, `#0d2818`, `#2d6a4f`, `#4ade80`
Заменить на новые цвета из theme.ts

### 2. Sidebar.tsx
Найти: те же цвета
Заменить на новые цвета из theme.ts

### 3. page.tsx
Найти: те же цвета
Заменить на новые цвета из theme.ts

### 4. globals.css
Найти: все hex цвета (#1a4d2e, #0d2818, #2d6a4f, #4ade80, #84a98c, #c8e6c9, #e8f5e9)
Заменить на новые цвета из theme.ts

## 🎨 Текущая палитра

### Темно-зеленые оттенки (основа)
- `#0a1612` - Самый темный фон
- `#0d2818` - Очень темный зеленый
- `#1a4d2e` - Темно-зеленый (основной)
- `#2d6a4f` - Средний зеленый

### Светлые акценты
- `#4ade80` - Яркий зеленый (заголовки, кнопки)
- `#84a98c` - Оливковый (подзаголовки)
- `#a5d6a7` - Приглушенный зеленый (текст)
- `#c8e6c9` - Светлый зеленый (вторичный текст)
- `#e8f5e9` - Очень светлый (основной текст)

### Дополнительные
- `#d4af37` - Золотой (предупреждения)
- `#ef4444` - Красный (ошибки)
- `#f59e0b` - Оранжевый (предупреждения)
- `#3b82f6` - Синий (информация)

## ⚡ Эффекты

### Анимация градиента фона
15-секундная анимация создает живой эффект движущегося градиента

### Тени
Все тени используют `rgba(13, 40, 24, 0.X)` для соответствия темно-зеленой теме

### Прозрачность
- Header: `/95` (почти непрозрачный)
- Sidebar: `/30` (полупрозрачный)
- Content: `/20` (очень прозрачный)
- Cards: `/20` (очень прозрачный)

## 🛠️ Инструменты для разработки

Используйте эти классы из `militaryClasses`:
- `header` - стили для header
- `sidebar` - стили для sidebar
- `content` - стили для основного контента
- `card` - стили для карточек
- `button` - стили для кнопок
- `title` - стили для заголовков

Пример:
```tsx
<div className={militaryClasses.card}>
  <h2 className={militaryClasses.title}>Заголовок</h2>
</div>
```
